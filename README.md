# torch-xray-vision
TorchXRayVision Flask Inference App — A minimal clinical-style web service that wraps pretrained chest X-ray models from mlmed/torchxrayvision￼. Upload a chest X-ray (JPG/PNG/DICOM) to predict possible pathologies and visualize a Grad-CAM heatmap explanation. Includes both a browser UI for clinicians and a REST API for programmatic access.
